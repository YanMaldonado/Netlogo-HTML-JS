# Netlogo-HTML-JS
A reproducible web-based agent-based simulation framework for analyzing coffee leaf rust infection dynamics under agrometeorological scenarios
Este repo contiene dos archivos uno es el código en el software NetLogo, para la simulación de la infección por Roya en parcelas de café
también esta otro archivo en html que se puede ejecutar en cualquier navegador web, y en cualquier dispositivo que soporte un navegador web.
